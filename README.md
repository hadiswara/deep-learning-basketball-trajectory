# Deep Learning — Prediksi Trajektori Bola Basket

Project UTS Deep Learning untuk memprediksi trajektori bola basket berdasarkan data tracking video.

## Isi Project
- YOLO tracking
- CSV exporter
- Train/test split kronologis
- Sliding window
- Model Simple RNN, LSTM, dan GRU
- Evaluasi dan visualisasi hasil
